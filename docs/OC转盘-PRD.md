## 1. 需求概述

### 1.1 需求背景

**个人处境**
- Futura 正在上头型课程（结构 → 五官 → 发型 → 肩颈连接），已具备画简单线稿的基础
- 上色暂用**单色/灰度**（色彩课未具体练）
- 个人口味偏**大透视 / 强动态 / 氛围感**，倾向"练就练完整的"
- 目标平台：**米画师 / 画加**（单主多为养 OC 或有特定角色需求，吃香有完成度、有辨识度的头像/胸像）

**核心问题**
1. 每天"不知道画谁"——缺低成本、可持续的出题机制
2. 手动拼标签太散、难坚持，需要随机 + 拼装
3. 练习容易偏个人口味，与接单"吃香角度/主题"脱节
4. 摇出"带感"的形象没有沉淀，随画随丢

### 1.2 产品目标

**用户目标**
- 一次点击、20 秒内出一个可画的"形象题"，过程**好玩、有节奏、有悬念**
- 练习内容对准接单吃香角度与主题
- 把"带感"的形象沉淀进待发展池，作为日后发展半身/立绘/插画的胚子

**北极星指标**
- 待发展池积累的"带感形象"数量
- （百日绘是外部方法，由 Futura 自己在小红书/手账记，工具不内置打卡）

### 1.3 产品范围

**本期范围（P0，已实现）**
1. 一键全流程：三排拉杆老虎机（朝向 + 打光）→ 球形摇号机（形象底子）→ 节气转盘（单色主题），全程自动流转，仅起点一次点击
2. 三种动画（见 3.0）
3. 结果卡（4 模块排版 + 右下小收藏图标）
4. 收藏 → 待发展池（收藏 / 回看 / 删除）
5. Web Audio 合成音效 + 音效开关

**P1（未实现）**
- 待发展池备注、导出（截图 / JSON）

**P2（未实现）**
- 分享、多色上色扩展（色彩课后）

**不在范围内**
- 百日绘打卡（由外部自行记录）
- 账号系统 / 多用户、AI 生图、接单客户管理、多色上色

### 1.4 依赖条件
- 标签池数据 `oc-wheel-data.json`（v3 已完成，17 转盘 / 315 词条 + 节气色 384 色值）
- 无后端，纯前端 + 本地存储

## 3. 功能需求

### 3.0 用户旅程故事线（核心链路，与代码一致）

> 全程只有**起点一次点击**，之后自动流转，用户只负责"看"和最后"要不要收藏"。

**第 0 秒 · 开场**
打开页面：中央一个扭蛋机投币口 + 大按钮【召唤今日OC】。

**① 朝向 + 打光 —— 三排拉杆老虎机**
- 点下按钮，投币"咔哒"，拉杆拉下，三列纵向格子带同时滚动：俯仰、水平、打光
- 三列由快到慢，先后停下（俯仰 → 水平 → 打光）
- 定格后四枚答案收进结果卡顶部标签区，画面让位

**② 形象底子 —— 球形玻璃摇号机**
- 自动切到摇号机：玻璃仓内 26 颗彩球持续翻滚，一颗颗滚出，每颗代表一格（脸型/眉/眼/…/头饰配饰）
- 每颗滚出即翻开该格答案（抽中值滚动闪现），13 颗依次滚完
- 13 个标签点亮进结果卡

**③ 单色主题 —— 节气转盘 + 起承转合四灯**
- 自动切到节气转盘：外圈 24 节气圆盘旋转减速定格，内圈「起承转合」四灯随机点亮一组
- 定格出「节气 · 组」，该组 4 个传统色作为卡片色带

**终章 · 结果卡**
- 4 模块收拢成一张卡：朝向（俯仰·水平）/ 打光/ 形象角色（13 格）/ 主色（节气·组 + 4 色带）
- 背景罩上对应打光光晕
- 右下角一枚小收藏图标（♡），点一下进待发展池

**节奏总表**

| 环节 | 动画形式 | 时长 |
|------|---------|------|
| 朝向 + 打光 | 三排拉杆老虎机 | ~4s |
| 形象底子 | 球形摇号机 ×13 | ~6s |
| 单色主题 | 节气转盘 + 起承转合四灯 | ~4s |
| **合计** | | **~15s** |

### 3.1 功能架构

```
OC转盘
├── 一键全流程（三排老虎机 → 摇号机 → 节气转盘）
├── 三种动画（老虎机 / 摇号机 / 节气转盘）
├── 结果卡（4 模块 + 收藏小图标）
├── 整体重摇（再来一次）
├── 收藏池（收藏 / 回看 / 删除）
├── 音效（Web Audio 合成 + 开关）
└── 数据层（oc-wheel-data.json v3）
```

### 3.2 核心功能

#### F1 转盘动画（三种形式）

**功能描述**：三个阶段各自独立的动画，完成一个自动切下一个，答案标签缩小保留。

**三种形式**
1. **朝向 + 打光**：三排纵向拉杆老虎机（俯仰 + 水平 + 打光），拉杆拉下，三列同时滚动、先后停
2. **形象底子**：球形摇号机——玻璃仓内彩球翻滚，一颗颗滚出翻开答案（13 格）
3. **单色主题**：节气转盘——外圈 24 节气圆盘旋转定格 + 内圈起承转合四灯点亮一组

**功能规则**
- 顺序固定：朝向+打光 → 形象底子 → 单色主题
- 已完成模块的答案标签**缩小保留**在结果卡区，为下一模块让出主画面
- 全程自动流转，无需中途点击；总时长 ≤ 20 秒
- 朝向 = 俯仰（5）× 水平（9）= 45 组合，一次同时出两值
- **三轴软约束**（形象底子内部）：
  - 气质（脸型/眉/眼/鼻/唇 + 后发/鬓发/锚点）：先抽「清冷英气 / 成熟柔美 / 可爱软萌」之一，从对应池 + 通用池抽，10% 概率混池（鬓发更软，25%）
  - 性别（前发/后发/鬓发/锚点/头饰配饰）：先抽「男 / 女」，从对应池 + 无性池抽
  - 风格（前发/后发/鬓发/锚点/头饰配饰）：先抽「古风 / 现代」，从对应池 + 通用池抽
- **需盘发硬约束**：发簪、步摇、发钗/凤钗、翠翘、华胜、头花/簪花 仅当后发为「可插簪发型」（盘发髻 + 半束披发 + 高马尾侠客头 + 高马尾）时出现，否则从头饰池排除
- **情绪软约束**（表情 → 肩颈与手）：手部动作分萌系/沉思系/强势系，表情分软萌/沉思/强势，抽选时 90% 情绪兼容 + 10% 放行
- **朝向权重**：俯仰 平视/微俯/微仰 ×3、超绝大俯/仰视 ×1；水平 正 ×2、左右微侧 ×4、半侧/¾侧 ×3、全侧 ×1；打光 正面光/顺光、蝴蝶光/派拉蒙光 ×3、伦勃朗/环形/分割光 ×2、其余 ×1
- **打光朝向约束**：底光/鬼光、蝴蝶光/派拉蒙光 仅当水平为正/微侧时出现
- **锚点「无」加权 ×5**（默认干净脸占大头），其余等概率

**验收标准**
- [x] 点一次按钮，三个模块按顺序自动完成，无需再次点击
- [x] 三排老虎机同时滚动、先后停
- [x] 形象底子摇号机一颗颗滚出，无长时间等待
- [x] 节气转盘定格出「节气·组」并点亮四灯之一
- [x] 结果卡罩上对应光影氛围

#### F2 结果卡

**功能描述**：4 模块简洁呈现，右下角小收藏图标。

**4 模块**：朝向（俯仰·水平）/ 打光/ 形象角色（脸型、眉、眼、鼻、唇、表情、后发、前发、鬓发、肩颈与手、领口、锚点、头饰配饰）/ 主色（节气·组 + 4 色带）

**交互**
- 底部「再来一次」按钮（整体重摇）
- 右下角一枚**小收藏图标（♡，视觉权重小，不抢戏）**

**验收标准**
- [x] 4 模块全展示，排版固定
- [x] 主色模块显示节气·组与 4 个传统色带
- [x] 收藏图标存在且点击进待发展池

#### F3 收藏 / 待发展池

**功能描述**：带感的形象一键收藏沉淀。

**规则**
- 收藏保存全字段快照 + 收藏时间
- 池内可回看（点击条目重新打开结果卡）、删除
- 数据存 localStorage

**验收标准**
- [x] 收藏后可回看完整快照
- [x] 删除可用，刷新不丢
- [ ] 备注（P1，未实现）

### 3.3 异常规则
- 数据文件缺失/损坏 → 提示错误，不崩溃
- 抽到"无"类标签 → 正常展示

### 3.4 已定项

### 3.5 视觉与交互规范

**整体风格**：复古游戏机风——像素感字体/边框、老虎机金属面板、霓虹灯光效。

**主按钮**：扭蛋机投币口形态——中央一个投币口 + 按钮，点击触发"咔哒"投币音效 → 进入动画流程；旁写「召唤今日OC」。

**三排拉杆老虎机**：金属面板质感、拉杆 + 三列纵向格子带；每格展示「标签 + 简单小图标」。

**形象底子摇号机**：立式玻璃仓——彩球翻滚，一颗颗滚落出来，每颗球落出即翻开一格答案。

**节气转盘**：传统圆盘，外圈 24 节气扇区填充该节气「起」组代表色；转动减速定格，内圈「起承转合」四灯随机点亮一组。

**结果卡**：扭蛋机出的胶囊卡形态——圆角厚卡片感 + 塑料光泽边框 + 主色做卡片底色 + 右下角小♡；**结果易读性第一**。

**打光**：结果卡下方背景叠加一层方向光晕（打光）。

**音效（Web Audio 合成，各环节均播放）**：

| 环节 | 音效 |
|------|------|
| 点击主按钮 | 投币"咔哒"声 |
| 三排老虎机 | 滚轮"咔咔"声 + 拉杆声 |
| 形象底子 | 小球碰撞声 + 落出"叮" |
| 节气转盘 | 转盘"滴答"指针声 |
| 结束 | 中奖"叮"声 |

**屏幕适配**：电脑为主，同时适配手机（响应式，转盘/老虎机等比缩放）。

## 6. 技术方案概述

- **形态**：纯静态单页（HTML/CSS/JS），无构建、无后端
- **动画**：CSS transition + requestAnimationFrame；老虎机用滚动位移、摇号机用弹跳碰撞、节气转盘用旋转、光影用渐变/光晕过渡
- **数据**：`data.js` 以 `window.OC_WHEEL_DATA` 全局变量注入（避免 file:// 下 fetch 的 CORS 限制）；收藏存 localStorage
- **音效**：Web Audio 合成（振荡器 + 噪声），无音频文件
